Tại sao mình học HTML, CSS và JavaScript?

Dù đam mê chính là làm game, mình nhận ra lập trình Web là một kỹ năng cực kỳ hữu ích. Nó giúp mình hiểu rõ hơn về cách các hệ thống hoạt động và hỗ trợ rất tốt cho tư duy logic.

Các ngôn ngữ và công cụ mình yêu thích

  • Ngôn ngữ Java và C
  • Phát triển Web (HTML, CSS, JS)
  • Hệ điều hành mã nguồn mở
